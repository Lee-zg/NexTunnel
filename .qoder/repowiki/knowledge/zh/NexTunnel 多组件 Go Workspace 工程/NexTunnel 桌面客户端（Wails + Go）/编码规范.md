- Wails 绑定的公开方法统一采用首字母大写的 Receiver 方法形式（如 `GetTunnels`、`StartTunnel`），参数与返回值使用带 `json:` tag 的结构体，以便前后端 JSON 序列化一致。
- 每个 `internal/<pkg>` 子包均提供 `doc.go` 用单行注释描述包职责，作为包级文档入口。
- 平台相关实现通过 Go build tag 拆分同名文件（如 `autostart_darwin.go`、`preflight_linux.go`、`tun_windows.go`），共享相同 package 名，避免条件编译散落在函数内部。
- 活动日志记录遵循固定字段模板：`Level`/`Category`/`Action`/`TargetType`/`TargetID`/`Title`/`Message`/`Metadata`，常量集中定义在 `app.go` 顶部（如 `activityAction*`、`activityLogLevel*`）。
- 错误处理统一走 `recordError`/`clearError` 配合 `lastErr` 字段，并在关键路径末尾追加 `appendActivityLog`，使错误与审计日志保持同步。
