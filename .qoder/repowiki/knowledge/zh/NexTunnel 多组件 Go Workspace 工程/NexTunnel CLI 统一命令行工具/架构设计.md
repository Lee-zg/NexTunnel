模块以 `main.go` 为唯一入口，通过 `command.NewRootCommand(version)` 组装根命令；子命令按职责拆分为独立文件：`config.go`(上下文配置)、`server.go`(本机服务端安装/启停/状态/日志/路径)、`remote.go`(远端登录/健康/节点/ACL/告警)、`desktop.go`(桌面端进程与 HTTP 控制)、`doctor.go`(环境检查)。

- 依赖方向单向向下：`command` → (`api`, `configstore`, `desktop`, `system`)，`api` 仅依赖标准库 `net/http`，`configstore` 仅读写 JSON 配置文件，`system` 封装路径与进程操作，`desktop` 封装桌面端控制文件与 HTTP 客户端。
- 所有对外网络访问统一走 `internal/api.Client`，支持 Bearer Token、10s 超时、响应体大小限制（4MB）以及自动解包 `{success,data,error}` 包裹格式。
- 用户级配置由 `internal/configstore.Store` 持久化到平台默认目录（Windows `%APPDATA%\NexTunnel\cli\config.json`，Unix `~/.nextunnel/cli/config.json`），权限 0600。
- 输出层 `output.go` 提供统一的 `writeData`，根据全局 `-o/--output` 标志在 table/json 间切换，table 模式对 `map[string]string` 做排序对齐输出。
- 版本字符串通过构建时 `-ldflags -X main.version=...` 注入，默认值为 `0.6.3-alpha`。
