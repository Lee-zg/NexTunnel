- 每个子命令以 `newXxxCommand(outputFormat *string, ...)` 工厂函数返回 `*cobra.Command`，并在 `NewRootCommand` 中集中注册。
- 需要读写的命令统一通过 `configstore.LoadDefault()` / `SaveDefault()` 获取并持久化 `Store`，避免直接操作文件系统。
- 所有远程 API 调用经 `api.NewClient(baseURL, token).Get/Post/Delete` 发起，禁止在命令层直接使用 `http.Get`。
- 命令返回值一律通过 `writeData(commandOutput(cmd), format, value)` 输出，而非直接 `fmt.Println`，以保证 `-o json` 一致生效。
- 跨平台差异通过 `runtime.GOOS` 分支处理（如 Windows 下禁用 systemd 相关 flag、桌面端二进制名选择）。
