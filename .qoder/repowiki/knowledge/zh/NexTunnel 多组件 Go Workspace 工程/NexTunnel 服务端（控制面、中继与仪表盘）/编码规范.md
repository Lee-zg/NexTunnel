- 每个 `cmd/*/main.go` 统一采用 `flag.NewFlagSet(name, flag.ExitOnError)` 收集参数，先构造默认配置再覆写，最后 `os.Exit(1)` 输出错误日志退出。
- Server 结构体提供 `NewXxx(cfg, ...opts)` 构造函数配合 `Option` 函数式选项注入 logger 等依赖，未显式传入时使用 `slog.Default()` 作为兜底。
- mTLS 启用模式一致：当 CA/Cert/Key 三者均非空时通过 `tlsutil.LoadServerTLS` 加载证书并用 `tls.NewListener` 包裹监听器，同时记录日志表明已启用 mTLS。
- 审计日志采用可选注入模式：若配置了审计路径则创建 `audit.NewJSONFileAuditLogger`，失败则回退为 `audit.NopAuditLogger{}`，不影响主流程启动。
- HTTP 路由集中注册在 `registerRoutes` 方法中，使用标准库 `mux.HandleFunc("METHOD /path", handler)` 风格，认证中间件统一包裹整个 mux。
