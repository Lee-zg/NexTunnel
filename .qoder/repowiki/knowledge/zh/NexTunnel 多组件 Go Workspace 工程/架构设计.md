根目录作为 monorepo 编排层，通过 `go.work` 声明 `cli / desktop / installer / pkg / server` 五个 Go 模块的 workspace 关系，使所有子模块共享同一份 `pkg` 基础库（协议编解码、TLS/mTLS、IPAM、路由等）。

- 运行时边界：CLI 调用 Control Plane HTTP API；桌面客户端通过 Wails 暴露本地控制接口并复用 `pkg` 中的 P2P/Relay/TUN 能力；服务端提供 control-plane、relay-server、dashboard 等多个二进制，均依赖 `pkg`。
- 前端隔离：desktop/frontend、installer/frontend、server/web 各自独立 npm 工程，由 Makefile 在 `build/package-*` 阶段分别打包。
- 发布产物：`make build-server` 产出 `build/control-plane`、`build/relay-server`、`build/dashboard`、`build/nat-detector`、`build/edge-rehearsal`、`build/ebpf-verify` 以及 `build/nextunnel` CLI，统一输出到仓库根 `build/`。
- CI/CD：`.github/workflows/ci.yml` 与 `release.yml` 基于顶层 Makefile 目标驱动全量 lint/test/build，配合 `.gocache-*` 缓存目录加速跨模块编译。
