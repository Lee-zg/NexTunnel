模块以 Go `main` 为入口，按职责拆分为以下层次：
- 进程与 UI 层：`main.go` 解析命令行、提权重入、选择 GUI 或 headless 分支；GUI 通过 `wails.Run` 启动，将 `App` 结构体绑定到前端。
- 业务编排层：`installer.go` 中的 `Installer` 是核心状态机，封装 Plan/Install/Uninstall 流程，负责 payload 校验、staging 目录解压、旧版本备份与原子 rename 替换、系统集成（注册表/快捷方式）、失败回滚。
- 平台抽象层：`platform.go` 定义 `PlatformIntegration` 接口，`platform_windows.go` 提供 Windows 实现（UAC 提权、taskkill、注册表卸载信息、PowerShell 创建 .lnk），`platform_other.go` 用于非 Windows 编译占位。
- 数据源抽象层：`payload_embed.go` 定义 `PayloadSource` 接口并由 `embeddedPayloadSource` 通过 `//go:embed payload/*` 加载 `manifest.json` 与 zip payload；`zip.go` 提供安全的 zip 解压与 SHA256 校验。
- 类型与常量：`types.go` 集中声明 `InstallOptions/InstallPlan/InstallProgress/InstallResult/PayloadManifest` 等跨层 DTO，以及阶段常量；`args.go` 解析 `--silent/--repair/--uninstall/--install-dir/--log/--no-launch` 等参数。
- 前端：`frontend/` 是 Vue3+Vite+TypeScript 单页应用，经 `wails.json` 的 `frontend:build` 脚本构建后由 `//go:embed all:frontend/dist` 打包进二进制，通过 `runtime.EventsEmit("installer:progress")` 与后端交互。
依赖方向：UI → App → Installer → (PayloadSource, PlatformIntegration)；平台与 payload 均通过接口解耦，便于测试与跨平台扩展。
