- 所有对外暴露的数据结构统一使用 JSON tag（如 `json:"install_dir"`），以便在 Wails 绑定的 Go 方法与前端 TypeScript 之间序列化。
- 平台相关操作通过 `PlatformIntegration` 接口抽象，具体实现放在 `platform_windows.go` / `platform_other.go` 中，用 `newPlatformIntegration()` 工厂函数返回，避免在业务逻辑中直接耦合 OS API。
- 长耗时操作采用 `context.Context` 传递取消信号，并在关键步骤检查 `ctx.Err()`，配合 `beforeClose` 钩子确保窗口关闭时能中断安装。
- 安装过程使用 staging 目录 + `os.Rename` 原子替换，并在失败路径调用 `rollbackInstall` 恢复 `.backup-*` 目录，保证升级可回滚。
- 进度回调统一通过 `reportProgress(report, phase, percent, message, error)` 包装，各阶段使用 `types.go` 中定义的字符串常量（如 `installPhaseExtracting`）作为 phase 值。
- 错误结果统一通过 `failedResult(err)` 构造 `InstallResult{Success:false, Error:...}`，避免在各处重复拼装失败响应。
